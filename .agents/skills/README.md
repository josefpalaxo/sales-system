# Local agent skills

Local skills follow the Agent Skills `SKILL.md` format and contain repeatable procedure, routing, safeguards, and output contracts.

They must resolve Circularo knowledge from current shared/domain records instead of embedding company facts. Add skills only after a repeated task and accountable maintainer are known.

- [`circularo-slides/`](circularo-slides/SKILL.md) provides the Circularo presentation design system, production workflow, and repository-routing rules.
- [`markdown-html-pack/`](markdown-html-pack/SKILL.md) converts selected Markdown files or folders into a self-contained offline HTML reader, with static Mermaid diagrams, navigation, search, source downloads, and print styling.
