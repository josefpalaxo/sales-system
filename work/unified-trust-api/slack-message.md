# Unified Trust API team Slack message draft

Hi team — I'm sharing a draft working pack for **Circularo Unified Trust API** to help us finalize the customer-facing materials.

The central message is **“One API for trusted digital execution.”** We want to broaden our current eSigning API story around orchestration: connecting document workflows, participant verification, approvals, signatures, seals, timestamps and evidence through a common REST API.

The folder includes positioning, a sales brief, an eight-slide pitch storyline, proposal copy, landing-page copy, five LinkedIn drafts and a blog draft, plus source material and review notes. These are working drafts for us to refine and approve.

Please use this pack to finalize six deliverables:

1. **Customer-facing slide deck** — turn the storyline into a branded deck with a clear transaction example and validated visuals.
2. **Customer-facing proposal / appendix** — finalize the introduction, benefits and corrected deployment structure for our proposals.
3. **Unified Trust API brochure** — create a concise branded overview using the same message and approved capability scope.
4. **New landing page** — finalize the web copy, design and implementation, with clear sales and developer CTAs.
5. **LinkedIn posts** — edit the drafts, create supporting visuals and agree the publication sequence.
6. **Blog article** — review the draft, add the final visual and links, and prepare it for publication.

Please keep the commercial model consistent: **there are no standalone API Plans**. Deployments can use **user-based or transaction-based subscriptions**, which cover **manual transactions only**. REST API Access is **included in Enterprise** and **purchased separately with Business**. Applicable **API eSealing / eSigning Transactions are mandatory for automated/API scenarios**. Additional consumption Add-Ons cover extra trust services such as KYC Verification, Qualified Seals and Qualified Timestamps.

Let's assign an owner to each deliverable, confirm the product claims and commercial wording, and agree the final assets and publication order.
