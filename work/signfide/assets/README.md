# SignFide assets

Brand concept boards and original generation prompts are preserved under `brand/`. Their files were moved intact from the former branding folder. See [current identity](../brand/README.md) and [concept history](../brand/concept-history.md).

The selected reference is [Good Faith alternative A](brand/good-faith-alternatives/a-wordmark.png). The original [Good Faith board](brand/02-good-faith.png) contains the superseded loop; it does not override the selected wordmark-only direction. Other palette/mark and [app-icon studies](brand/app-icon-explorations/c-sf-ligature.png) remain explorations, not production masters or approved icon choices.

These raster studies are not exact custom lettering, flat-color/vector originals or tested small-size deliverables. Final geometry, production exports, monochrome treatment, clear space, rights and accessibility tests remain open in SF-OQ-025. Generation prompts are retained beside their boards. The prototype keeps its local copied reference and fonts/licenses so it remains runnable independently.

Do not store credentials, private records or fabricated product/customer proof as assets. Add a purpose, rights/source and usage note when introducing real screenshots, logos or third-party imagery.
