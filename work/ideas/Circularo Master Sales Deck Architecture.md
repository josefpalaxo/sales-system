# Circularo Master Sales Deck Architecture

Circularo maintains three primary sales narratives:

1. Circularo SaaS — Enterprise Digital Trust Platform
2. Circularo Sovereign — Self-Hosted Trust Platform
3. Circularo Sovereign Shared Services — National / Government-Wide Trust Infrastructure

These are not deployment variants of the same presentation.

Each addresses a different buying problem while following the same narrative structure:

1. Unique Insight
2. Current Alternatives
3. Ideal State
4. Introducing Circularo
5. Why Circularo Is Different
6. Proof
7. Address the Concerns
8. Next Step
