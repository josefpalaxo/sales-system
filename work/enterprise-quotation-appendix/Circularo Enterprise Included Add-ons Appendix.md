# **Appendix — Circularo Enterprise Plan: Included Add-ons and Benefits**

**Circularo Enterprise** brings together advanced capabilities that help organizations manage approvals, reduce document preparation effort, connect business systems and provide a familiar experience for employees and external recipients.

The following add-ons are included with the Enterprise Plan, alongside its standard features. Inclusion covers the stated capability; activation, customer prerequisites and any separately chargeable services or consumption are addressed below. Plan inclusion is based on the [Circularo plan comparison](https://www.circularo.com/pricing/#compare-plans).

## **Greater visibility and control over approvals**

| Included add-on | What it provides | Key benefit |
| :---- | :---- | :---- |
| **Advanced Reporting** | Detailed transaction and pending-transaction reports for organization administrators, showing progress, participants and outstanding actions. | **Focus follow-up where it matters.** Identify delayed approvals and give process owners clearer information for operational reviews. |
| **Transaction Controller** | A designated role that can inspect transaction metadata and take over or reassign document ownership to resolve processing obstacles. | **Keep work moving when ownership becomes a bottleneck.** Give authorized staff a practical way to recover stalled transactions. |
| **Contract Deadlines & Renewals** | Tools to manage contract terms, renewal dates and reminders, including agreements without a fixed end date. | **Act before important contract dates.** Bring renewal follow-up into the document process and reduce reliance on separate calendars and spreadsheets. |

Advanced Reporting is available to organization administrators. Controller access to transaction metadata does not itself grant access to document contents; permissions remain part of the agreed configuration. See [Advanced Reporting](https://help.circularo.com/en/add-on-advanced-reporting).

## **Faster preparation and connected document processes**

| Included add-on | What it provides | Key benefit |
| :---- | :---- | :---- |
| **Pre-Fill Documents with 3rd-party Data** | Populates document fields with information from external systems through a configured connection. | **Reduce repeated data entry.** Reuse existing business information to prepare documents more consistently and reduce transcription errors. |
| **REST API** | API access for developing integrations and automating document processes with other business applications. | **Connect documents to the wider business process.** Reduce manual hand-offs between systems and make document actions part of existing applications. |
| **PDF Form Field Recognition** | Detects existing fillable fields in uploaded PDF forms so they can be reused when preparing documents and templates. | **Put existing forms to work sooner.** Reduce the manual effort of placing fields when converting established PDF forms into signing templates. |
| **AI Document Assistant** | Generates summaries and key points, identifies personal information and suggests document categories, labels and sensitivity classifications. | **Help reviewers get to the relevant information faster.** Support initial review and consistent document organization, with users retaining control over which suggestions to apply. |

API access enables integration development; custom implementation and automated trust-service consumption are separate. AI Document Assistant requires customer-managed AI provider credentials, with provider usage charged separately. See [REST API](https://help.circularo.com/en/add-on-rest-api-for-custom-integrations) and [AI Document Assistant](https://help.circularo.com/en/how-to-ai-assistant).

## **A recognizable organizational identity**

| Included add-on | What it provides | Key benefit |
| :---- | :---- | :---- |
| **Custom E-mail Identity** | Sends Circularo notifications and signing requests through the organization’s own email infrastructure and domain. | **Make requests easier to recognize.** Present a familiar sender identity to employees, customers and partners. |
| **Custom Domain** | Makes Circularo accessible through a domain owned by the organization. | **Create a familiar point of access.** Bring the document service into the organization’s existing digital environment. |

These capabilities require the relevant email and domain configuration. Changes to logos, colors, application naming or notification wording are separate customization options. See [Custom E-mail Identity](https://help.circularo.com/en/add-on-custom-email-identity) and [Custom Domain](https://help.circularo.com/en/add-on-custom-domain).

## **Access, identity and user lifecycle management**

| Included add-on | What it provides | Key benefit |
| :---- | :---- | :---- |
| **SAML 2.0 Single Sign-On** | Connects Circularo authentication to a compatible organizational identity provider. | **Simplify employee access.** Let staff sign in with their existing organizational credentials and align authentication with the organization’s identity environment. |
| **Automated User Provisioning (SCIM)** | Synchronizes user creation, account updates and deactivation from a compatible corporate identity provider, keeping users and teams aligned with the configured directory assignments. | **Reduce manual account administration throughout the employee lifecycle.** Streamline onboarding, reflect changes as staff move between teams, and deactivate accounts when access is withdrawn in the directory, helping reduce the risk of outdated accounts retaining access. |
| **UAE PASS Identity Verification** | Supports user authentication and verification of external recipients through UAE PASS. | **Add a familiar identity check for UAE users.** Strengthen confidence in who is accessing the service or receiving documents. |

SAML manages sign-in, while SCIM automates account lifecycle changes. Both require identity-provider configuration; SCIM synchronization follows the agreed directory assignments and provisioning settings. UAE PASS Identity Verification requires the applicable service activation and approvals; UAE PASS document signing is a separate add-on. See [SAML Single Sign-On](https://help.circularo.com/en/add-on-saml-2-0-sso), [SCIM configuration](https://help.circularo.com/en/how-to-setting-up-scim) and [UAE PASS Identity Verification](https://help.circularo.com/en/add-on-uae-pass-identity-verification).

## **Flexibility in how documents are signed**

| Included add-on | What it provides | Key benefit |
| :---- | :---- | :---- |
| **Signature Provider Selection** | Allows the user to choose among available, enabled signature providers during a signing session. | **Match signing to the recipient and process.** Use the appropriate configured provider for different document scenarios. |
| **Signature Mode Selection** | Supports a choice between a composite signature that seals the completed document and individual signatures that apply an electronic certificate at each signing event. | **Choose the signing approach suited to the process.** Align document execution with the organization’s certificate and review requirements. |

Provider selection does not include third-party signing services, their consumption or qualified certificates. Those services require their own activation and commercial arrangements. Signature modes do not by themselves create a qualified signature. See the [add-on overview](https://help.circularo.com/en/add-on-overview).

## **Activation and commercial scope**

The quotation and order schedule specify the licensed users, subscription term, allowances, selected services and activation scope. Technical configuration and customer inputs may be needed before a capability can be used. Any additional professional services, custom integration work, third-party fees and consumption packs will be identified separately.

Enterprise also offers optional paid extensions. **Custom Application Name, Custom Upload Form, Custom Web Forms are available at additional cost**, as shown in the [plan comparison](https://www.circularo.com/pricing/#compare-plans). These optional extensions are included in a quotation only when expressly listed.

Other separately priced options include expanded storage and standalone document management, SMS services, KYC services, and qualified timestamps, signatures and seals. API access does not include automated signing or other API-initiated trust-service consumption. AI provider consumption is billed separately by the selected provider.

## **Optional Add-Ons**

| Optional add-on | What it provides | Key benefit |
| :---- | :---- | :---- |
| **Custom Application Name** | Replaces the default application name with your organization’s chosen name, retaining “powered by Circularo” attribution. Requires Custom Branding and Styling. | **Create a recognizable organizational service.** Reinforce your identity and make the application feel familiar to employees and external users. |
| **Custom Upload Form** | Adds document-specific fields at upload to capture information such as department, document type and reference number. | **Capture consistent information from the start.** Improve document classification and reduce missing details, manual corrections and follow-up. |
| **Custom Web Forms** | Provides public web forms for collecting data and documents through an external website and initiating approval or signing processes in Circularo. | **Turn online submissions into actionable processes.** Simplify intake for customers, partners and applicants while reducing email exchanges and repeated data entry. |

| **KYC Identity Verification** | Verifies an individual’s identity by checking a government-issued ID and matching it against a biometric selfie with liveness checks. Supports thousands of ID types across more than 190 countries. | **Build confidence in who you are dealing with.** Streamline remote onboarding, reduce manual identity-checking effort and support consistent verification across international customers and partners. |
