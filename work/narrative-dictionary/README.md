# Circularo Narrative Dictionary

## Purpose

This working catalog is the common language reference for Circularo-related presentations, web copy, brochures, partner enablement, discovery, and internal narrative development.

It consolidates the strongest current terminology without turning working language into approved product or company truth. The governed repository remains authoritative. When a catalog entry points to an approved stable record, use that record for exact rules and claims.

## Fast-start vocabulary

Use this hierarchy when framing Circularo:

1. **Digital trust infrastructure** — broad market context.
2. **Trusted execution infrastructure** — the emerging requirement created by automated and agentic work.
3. **Circularo Unified Trust Platform** — working platform proposition; owner validation required.
4. **Trusted Execution Layer** — Circularo's working architectural role between actors, institutional controls, trusted actions, and evidence.
5. **System of Authority** — working strategic outcome, not yet an established external category.

Use these delivery narratives:

- **Circularo SaaS** — managed trusted execution.
- **Circularo Sovereign** — customer-controlled trusted execution.
- **Sovereign Trust Shared Services** — reusable sovereign trust infrastructure across multiple entities.

Use this core mechanism:

> Actor → Authority → Policy → Approval → Execution → Evidence → Audit

Use this value progression:

> Trusted action → Trusted execution → Trusted and verifiable outcome → Trusted record → Institutional memory → Trusted AI context → Governed action

## Primary terminology decision

Use **trusted action** or **trusted business action** in new audience-facing content. Do not use **consequential action** as the default phrase.

- A **trusted action** is the specific business act being prepared, approved, executed, and evidenced.
- **Trusted execution** is the governed lifecycle that carries the action from authority and policy through execution and evidence.
- A **trusted outcome** is the resulting business or institutional state produced through that governed execution.
- A **verifiable outcome** is an outcome that can be substantiated later through connected evidence and a trusted record.

Use **trusted and verifiable outcomes** as the customer-value expression when the message should emphasize what Circularo helps the institution achieve rather than the underlying execution mechanism.

This decision applies to new decks, web content, brochures, enablement, and revisions of working material. Historical sources remain unchanged.
