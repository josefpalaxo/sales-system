# Source snapshots

This directory preserves immutable source material used during migration or when an external source cannot provide durable locators.

Snapshots are evidence, not automatically canonical. Their source-register records define authority, classification, and migration state.

The active Commercial Model and Add-On Model are in the [commercial library](../shared/commercial/README.md). Their copies under `archived-snapshots/` remain historical migration evidence. Edit the active master, not its historical snapshot. The preserved sales-repo Commercial Model is an older differing input, not a second active authority.

The [investor source collection](investor-context/README.md) retains the original mandate and inspection provenance. [API source inputs](api/unified-trust-api/) retain the supplied specification and changelog. The [restructuring path map](../work/repository-restructure/path-map.json) resolves historical locations; archived inspection paths and fingerprints are not rewritten as new evidence.
