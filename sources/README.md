# Source snapshots

This directory preserves immutable source material used during migration or when an external source cannot provide durable locators.

Snapshots are evidence, not automatically canonical. Their source-register records define authority, classification, and migration state.

The active Commercial Model and Add-On Model are now in the [master document library](../shared/master-documents/README.md). Their copies under `archived-snapshots/` remain historical migration evidence. Edit the active master, not its historical snapshot. The preserved sales-repo Commercial Model is an older differing input, not a second active authority.
