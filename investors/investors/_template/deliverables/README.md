# Deliverables

Tailored teaser, investment brief, pitch-deck outline, talking points, follow-up draft, valuation analysis or strategic opportunity material.

Follow [workspace guidance](../README.md) and the [master](../../../master/investor-materials-master.md). No actual deliverables created at setup.

Each deliverable must record master revision/source IDs, reporting periods, as-of date, audience, owner, draft/approval status and classification. Separate evidence from assumptions. Sending a follow-up or sharing a deliverable requires human authorization. Keep one stable basename per durable asset.
