# Common investor materials

Generic investor assets are derived from the [master](../master/investor-materials-master.md); they never become a second factual authority. Initial setup creates folders only, with no polished decks or investor-facing claims.

| Folder | Stable intended asset |
| --- | --- |
| [teaser/](teaser/README.md) | Investor teaser |
| [pitch-deck/](pitch-deck/README.md) | Strategic investor deck |
| [one-pager/](one-pager/README.md) | Investor one-pager |
| [investment-memo/](investment-memo/README.md) | Investment thesis / memo |
| [talking-points/](talking-points/README.md) | Executive talking points |
| [faq/](faq/README.md) | Investor FAQ |
| [data-room-index/](data-room-index/README.md) | Data-room index and controlled locators |

Each deliverable must record intended audience, status, classification, owner, master revision/source IDs, reporting periods, as-of date and exact external-sharing approval. Label forecasts, scenarios, roadmap and vision explicitly. Use one stable basename and Git history for revisions.

Investor-tailored derivatives belong in that investor's `deliverables/` folder. Raw data-room evidence stays in its controlled system.
