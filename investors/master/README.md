# Master investor knowledge

Read the [executive master](investor-materials-master.md) first. Detailed records below own common facts; investor workspaces reference them. Initial content is draft and confidential; see [governance](../GOVERNANCE.md).

| Area | Scope |
| --- | --- |
| company/ | Identity, history, team, ownership and funding |
| business/ | Business model, deployments, go-to-market and commercial references |
| strategy/ | Strategic vision, growth and shareholder contribution |
| product/ | Positioning, roadmap and architecture maturity |
| traction/ | Dated metrics, customer evidence and deployments |
| financials/ | Historical actuals, ARR, revenue quality, forecasts and valuation context |
| market/ | Evidence-backed market and competitive context |
| transaction/ | Management-authorized transaction parameters |
| risks/ | Investor questions, mitigation and due diligence |

[Data quality and open questions](data-quality-and-open-questions.md) tracks missing evidence, stale material and conflicts. Never interpret an empty field as zero or a named verification target as an established customer.

The master is not approved as a whole. Use each claim's source, reporting period, evidence state and approval scope. Assign accountable owners and review dates before approving records.
