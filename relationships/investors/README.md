# Investor relationships

Use this area for individual investors, advisers, brokers and outreach. Common facts and reusable materials live in [investor preparation](../../shared/playbooks/investors/README.md).

- [Qubit Capital](qubit-capital/README.md) — fundraising broker context.
- [Jahani & Associates](jahaniandassociates/) — relationship preparation and authored briefing.
- [Vortex Capital](vortexcapital/) — strategic-shareholder preparation.
- [Outreach](outreach/README.md) — explicitly authorized confidential research, contacts and tracking; existing handling restrictions continue.

For a new relationship, use the [template](../../shared/templates/investor-relationship/README.md) as needed. Keep one stable folder per counterparty and no nested Git repository. Do not copy shared facts into a second maintained master.

Read [agent instructions](AGENTS.md) and the [investor governance](../../shared/playbooks/investors/governance.md). External sharing requires approval for the exact deliverable and audience. Run validation from the repository root with `rtk make validate`.
